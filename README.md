# VideoKeşfet MVP

Bu paket, Supabase veritabanına bağlanan ilk çalışan frontend prototipidir.

## Kurulum
1. `npm install`
2. `.env.example` dosyasını `.env` olarak kopyala.
3. Supabase Project URL ve anon key değerlerini `.env` içine koy.
4. `npm run dev`

## Not
- Videolar ilk sürümde `pending` olarak kaydedilir.
- Sadece `approved` videolar keşfet sayfasında gösterilir.
- YouTube izlenmesi karşılığında puan verilmez.
